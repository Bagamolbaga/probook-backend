# Документ концепции проекта

## Название проекта
Система онлайн-записи "ProBook"

## Краткое описание сути проекта
ProBook — это веб-платформа для управления записями на услуги. Бизнесы могут зарегистрироваться, вести учет своих работников и услуг, а также просматривать записи в удобном календаре. Клиенты получают возможность записаться на прием или услугу через персонализированную веб-страницу бизнеса, выбрав подходящие услуги, день и время.

## Цель
Основная цель проекта — упростить процесс управления записями для малого и среднего бизнеса в сфере услуг, минимизируя ручной труд и снижая количество пропущенных встреч за счет автоматизированной онлайн-записи.

## Аналитический обзор
Конкуренты или альтернативы

1. YCLIENTS — российская платформа для автоматизации бизнеса в сфере услуг, с акцентом на онлайн-запись, управление расписанием и интеграциями.
2. DIKIDI Business — бесплатная базовая версия для онлайн-записи, подходящая для малого бизнеса, с фокусом на мобильные приложения и аналитику.
3. Altegio — система для управления сетевыми бизнесами, с сильным упором на многофилиальность, уведомления и финансовую аналитику.
4. SimplyBook.me — международная платформа с гибкой настройкой, поддержкой групповых booking и интеграциями с социальными сетями

## Результаты проекта
### В каком виде реализовано
Проект реализован в виде веб-сайта, доступного через браузер на десктопных и мобильных устройствах. Возможна дальнейшая разработка мобильного приложения.

### Ключевые высокоуровневые функциональные требования

1. Бизнес может зарегистрироваться в системе с указанием контактных данных.
2. Бизнес может добавлять и редактировать список работников с их расписаниями.
3. Бизнес может создавать и управлять списком услуг, включая описание, длительность и стоимость.
4. Система предоставляет календарный вид для просмотра всех записей бизнеса.
5. Клиенты могут открыть веб-страницу бизнеса и просмотреть доступные услуги.
6. Клиенты могут выбрать услугу, свободный день и время для записи.
7. Система автоматически обновляет календарь после подтверждения записи.
8. Бизнес получает уведомления о новых записях по email.
9. Клиенты получают подтверждение записи по email.
10. Бизнес может отменять или переносить записи с уведомлением клиента.
11. Система хранит историю записей для аналитики.
12. Поддержка поиска свободных слотов в реальном времени.
13. Автоматическая проверка на конфликты расписания.
14. Аналитика по записям и посещаемости.
15. Базовая аналитика: количество записей за период, популярные услуги.

### Допущения и ограничения

1. Допущение: Все пользователи имеют доступ к интернету и веб-браузеру.
2. Допущение: Бизнесы работают в сфере услуг с фиксированными слотами времени.
3. Ограничение: Система не поддерживает интеграцию с внешними платежными системами на начальном этапе.
4. Ограничение: Максимум 50 работников на один бизнес-аккаунт.
